War Chronicle Browser Update 0538

Update 0538 (v0.5.0.38):
- Unavailable choices inside Scene, Explore, Arrival, Echo, and Camp card flows now remain visible instead of disappearing.
- Disabled choices explain why they cannot currently be selected, using the same player-facing pattern already used by unavailable Camp actions.
- This fixes cases such as Cursed Battlefield (no eligible Infantry-class Unit) and A Wager of Flesh (no eligible fighter).
- Hidden/random downstream information remains concealed; the change applies only to player-facing Choice branches and visible prerequisites.
- Major persistent setbacks now receive stronger Chronicle emphasis without interrupting play: destroyed Buildings, lost controlled Settlements, and damaged Baggage Train spaces use a warning treatment.
- Bumped CSS/helper/data cache tokens and app version to 0538. SaveVersion remains 1.

Install/deploy this package the same way as prior browser updates.
